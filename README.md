## 🚀 How to Enable GitHub Pages

To host this resume online:

1. Push these changes to your repository (`main` branch):
   ```bash
   git add .
   git commit -m "Update resume with complete professional experience"
   git push origin main
   ```
2. In your GitHub repository, click **Settings** (top menu bar).
3. In the left sidebar under the *Code and automation* section, click **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Select `main`
   - Select `/ (root)` folder
   - Click **Save**
5. Within 1-2 minutes, GitHub will publish your site and display your live URL: `https://quaijin.github.io/LBCyberDefense/`.
