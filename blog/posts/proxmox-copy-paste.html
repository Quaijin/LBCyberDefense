Enabling Copy & Paste in Proxmox

By default, Proxmox uses noVNC, which does not support clipboard functionality. Here are three ways to enable it.

Using VNC Clipboard

  1. Enable clipboard in Display settings.
  2. Insert virtio driver file in VM.
  3. Reboot.

Using xterm.js

Add a Serial Port, edit /etc/default/grub:

GRUB_CMDLINE_LINUX_DEFAULT="quiet console=tty0 console=ttyS0,115200"

Restart and select xterm.js in the console menu.

Using SPICE

Set Display to SPICE, install Virt-viewer on your client, and select SPICE in the console menu.
