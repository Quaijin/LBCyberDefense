Proxmox LXC SSH Setup Guide

How to configure passwordless SSH access for an LXC container.

1. Generate Keys

ssh-keygen -t ed25519 -f "$HOME\.ssh\id_proxmox_lxc"

2. Configure in Proxmox

Paste the public key (.pub file) into the SSH public key field during container creation.
