Proxmox VM Migration Guide

Phase 1: Connectivity Audit

Check interface configurations on both nodes: ip -br -c a

Test connectivity: ping [IP_OF_OTHER_NODE]

Phase 2: Transfer

Use scp to move the backup file:

scp /var/lib/vz/dump/backup.vma.zst root@destination:/var/lib/vz/dump/

Phase 3: Restore

qmrestore /var/lib/vz/dump/backup.vma.zst 101 --storage local-lvm
